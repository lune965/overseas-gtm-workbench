Overview

项目简介

海外GTM工作台（Overseas GTM Workbench）是一款面向消费电子（Consumer Electronics）品牌出海的售前与市场辅助工具，覆盖方案匹配、市场策略、社媒营销三大核心功能模块。帮助出海团队快速生成方案简报、获取市场策略建议、规划社媒内容营销。

技术栈 Python 3 + Streamlit + Pandas

目标市场 北美 · 欧洲 · 东南亚 · 中东

产品数量 12 个消费电子产品，覆盖 7 个品类

启动方式 streamlit run app.py，秒级部署

在线演示 https://overseas-gtm-workbench-nj2sch7lmyxlkl4pt5ba8g.streamlit.app/

Features

功能概述

📋 方案匹配

4 维筛选（目标市场 / 使用场景 / 核心诉求 / 预算）+ 标签评分算法，自动推荐 3 款产品组合，生成英文 Solution Brief，支持 Markdown 导出。

📈 市场策略

覆盖北美、欧洲、东南亚、中东四大市场，自动生成市场概况、渠道策略、定价建议、本地化清单，侧边栏切换实时联动。

📱 社媒营销

预热期→发布期→留存期全周期管理，含内容形式矩阵、生产 Checklist、素材库（CSV 导出）、英文帖文生成器（12 种模板）。

Technology

技术架构

🎨 Streamlit 前端

响应式 Web UI，宽屏布局，自定义 CSS 深蓝主题

🧠 匹配引擎

标签评分算法，场景权重 ×2 + 品类权重 ×1 + 预算优先

📝 方案生成器

模板引擎渲染英文 Solution Brief，支持 Markdown 下载

📦 JSON 数据层

产品数据独立存储，无需数据库，开箱即用

🌐 双语适配

界面中文 + 产品/内容英文，自动映射转换

📥 文件导出

Markdown + CSV 双格式导出，BytesIO 流下载
