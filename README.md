## 🎯 项目背景

消费电子品牌出海已成为中国制造的重要增长引擎。售前与市场团队在与海外客户沟通时，需要快速根据客户需求匹配产品方案、制定市场策略、规划社媒内容。目前缺乏一套轻量级的一站式辅助工具来提升效率。

**本工具的目标是：**

1. 帮助售前人员快速录入客户需求（目标市场 / 使用场景 / 核心诉求 / 预算）
2. 自动匹配最合适的 3 个产品组合并生成方案简报
3. 为不同海外市场提供专业的市场进入策略建议
4. 覆盖产品发布全周期的社媒内容规划和帖文生成

## ✨ 功能特性

### 📋 Tab 1：方案匹配

| 功能 | 说明 |
|------|------|
| 🔍 **4 维筛选** | 目标市场、使用场景、核心诉求、预算范围，精确定位需求 |
| 🧠 **智能匹配引擎** | 基于标签评分算法，场景权重 ×2 + 品类权重 ×1 + 预算优先过滤 |
| 📦 **产品卡片展示** | 横向展示 3 个产品卡片，含英文名、描述、场景标签、价格档位 |
| 📝 **英文方案简报** | 自动生成专业的英文 Solution Brief |
| 📥 **Markdown 导出** | 一键下载完整的方案简报 `.md` 文件 |

### 📈 Tab 2：市场策略

| 功能 | 说明 |
|------|------|
| 📊 **市场概况** | 针对 5 大目标市场的中文市场分析 |
| 📡 **渠道策略** | 线上（Shopee/Lazada/Amazon）+ 线下配比建议 |
| 💰 **定价建议** | 按市场购买力和预算档位给出的定价指引 |
| 🌐 **本地化清单** | 认证要求、文化习惯、支付方式等注意事项 |

### 📱 Tab 3：社媒营销

| 功能 | 说明 |
|------|------|
| 📅 **阶段管理** | 预热期 / 发布期 / 留存期，分阶段运营策略 |
| 📋 **内容形式矩阵** | 每阶段推荐 4-5 种内容形式（平台/篇幅/方向/频率） |
| ✅ **Checklist** | 阶段联动待办清单，勾选状态独立保存 |
| 📚 **内容素材库** | 6 条示例数据，支持导出 CSV |
| ✍️ **帖文生成器** | 3 阶段 × 4 类型 = 12 种英文帖文模板，支持编辑修改 |

## 🚀 快速开始

### 环境要求

- Python 3.8 或更高版本
- pip 包管理器

### 安装与启动

```bash
# 1. 进入项目目录
cd smart-home-presales-tool

# 2. 安装依赖
pip install -r requirements.txt

# 3. 启动应用
streamlit run app.py
```

启动后浏览器会自动打开 `http://localhost:8502`（可通过 `--server.port` 自定义端口）。

### 自定义端口

```bash
streamlit run app.py --server.port 8080
```

## 🎮 使用指南

### 侧边栏筛选（所有 Tab 共享）

在左侧侧边栏中依次选择：

| 字段 | 选项 |
|------|------|
| 🌏 **目标市场** | 东南亚 / 中东 / 拉美 / 欧洲 / 北美 |
| 🎯 **使用场景** | 户外运动 / 日常通勤 / 商务办公 / 游戏娱乐 / 旅行出差 |
| ⭐ **核心诉求** | 音质表现 / 续航能力 / 快充技术 / 便携设计 / 智能互联 / 耐用性 |
| 💰 **预算范围** | 入门 / 中端 / 高端 |

> 所有条件均为下拉选择，切换后右侧结果区域**实时更新**，无需点击任何按钮。

### Tab 1：查看推荐产品

右侧展示 3 款推荐产品卡片，每款包含：
- 产品名（英文，加粗）
- 一句话英文描述
- 适用场景标签
- 价格档位 + 品类

下方自动生成英文方案简报，可点击 **"📥 导出方案简报"** 下载为 Markdown 文件。

### Tab 2：查看市场策略

根据侧边栏选择的目标市场和使用场景，自动生成：
- 市场概况分析
- 渠道策略（线上+线下配比）
- 定价建议
- 本地化注意事项

### Tab 3：社媒营销工作台

1. **选择阶段**：预热期 / 发布期 / 留存期
2. **查看内容形式矩阵**：当前阶段推荐的内容形式
3. **勾选 Checklist**：跟踪内容制作进度
4. **查看素材库**：可导出的内容管理表格
5. **生成英文帖文**：选择帖文类型，自动生成英文草稿

## ⚙️ 推荐引擎原理

本工具采用**基于标签的评分匹配算法**：

```
输入: 市场 + 场景 + 诉求 + 预算
           ↓
   识别匹配标签，计算评分
           ↓
   场景匹配 → 权重 2
   品类匹配 → 权重 1
           ↓
   按评分降序排列
           ↓
   预算优先过滤 → 精确匹配优先
           ↓
   相邻预算补充 → 不足时拾取
           ↓
   输出 Top 3 推荐
```

### 匹配规则详细

```python
# 场景 → 品类映射示例
"户外运动" → ["Outdoor", "Sports"]
"日常通勤" → ["Commute", "Daily"]

# 诉求 → 品类映射示例
"续航能力" → ["充电", "穿戴"]
"音质表现" → ["音频"]
```

## 🗂️ 项目结构

```
overseas-gtm-workbench/
│
├── app.py                      # 🔹 主入口 — Streamlit Web 应用
├── requirements.txt            # Python 依赖清单
├── README.md                   # 项目说明文档（本文件）
├── portfolio.html              # 作品集展示页面
├── .gitignore                  # Git 忽略规则
│
├── data/
│   └── products.json           # 内置产品目录（12 个消费电子产品）
│
├── engine/                     # 核心业务逻辑
│   ├── __init__.py
│   ├── matcher.py              # 标签评分匹配引擎（支持中文输入映射）
│   └── generator.py            # 方案简述生成器 + Markdown / CSV 导出
│
└── docs/
    ├── requirements.md         # 需求文档
    └── development-plan.md     # 开发计划
```

### 核心文件职责

| 文件 | 职责 |
|------|------|
| `app.py` | Streamlit 主入口：3 个 Tab 布局、侧边栏交互、UI 渲染 |
| `engine/matcher.py` | 匹配引擎：中文输入映射、标签评分、排序选取 |
| `engine/generator.py` | 方案生成器：英文 Solution Brief 模板、Markdown 导出 |
| `data/products.json` | 12 个消费电子产品数据 |
| `portfolio.html` | 独立作品集展示页面 |

2. 登录 https://share.streamlit.io/
3. 点击 **New app**，选择本仓库
4. 部署后自动生成公网链接
