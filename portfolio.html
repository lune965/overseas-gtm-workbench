Overview

项目概览

智能方案匹配引擎

根据目标市场、使用场景、核心诉求和预算范围，从产品库中智能匹配合适的产品组合。

  • 4 维筛选 — 市场 / 场景 / 诉求 / 预算，精确定位需求
  • 标签评分算法 — 多因素加权排序，精准推荐 Top 3
  • 产品卡片展示 — 产品名（加粗）+ 英文描述 + 场景标签 + 价格档位
  • 英文方案简报 — 自动生成专业的 Solution Brief（Markdown）
  • 一键导出 — 下载 .md 文件，可直接用于客户提案
  • 兜底策略 — 匹配不足时自动从相邻品类补充，确保始终有推荐

市场进入策略

针对不同海外市场，自动生成专业的市场分析报告和策略建议。

  • 市场概况 — 各市场规模、增长趋势、竞争格局分析
  • 渠道策略 — 线上（Shopee/Amazon/Noon）vs 线下推荐配比
  • 定价建议 — 按市场购买力和预算档位细分定价
  • 本地化清单 — 认证要求、文化习惯、支付方式等注意事项
  • 5 大市场覆盖 — 北美 / 欧洲 / 东南亚 / 中东 / （框架预留拉美）
  • 实时联动 — 切换侧边栏条件，策略内容自动更新

社媒营销工作台

覆盖产品发布全周期的社媒内容规划和英文帖文生成。

  • 阶段管理 — 预热期 / 发布期 / 留存期，分阶段运营策略
  • 内容形式矩阵 — 每个阶段推荐 4-5 种内容形式，含平台/篇幅/频率
  • Checklist — 阶段联动待办清单，勾选状态独立保存
  • 内容素材库 — 6 条示例数据，支持导出为 CSV
  • 英文帖文生成器 — 3 阶段 × 4 类型 = 12 种帖文模板
  • 帖文可编辑 — text_area 展示，支持直接修改后再导出

📂 项目结构

smart-home-presales-tool/
├── app.py                      # 主入口 — Streamlit Web 应用（~735 行）
├── requirements.txt            # Python 依赖清单
├── README.md                   # 项目说明文档
├── .gitignore                  # Git 忽略规则
├── data/
│   └── products.json           # 内置产品目录（12 个消费电子产品）
├── engine/                     # 核心业务逻辑
│   ├── __init__.py
│   ├── matcher.py              # 标签评分匹配引擎
│   └── generator.py            # 方案简述生成器 + Markdown 导出
└── docs/
    ├── requirements.md         # 需求文档
    └── development-plan.md     # 开发计划
